# Messages clés

## Message 1

Le dashboard ne mesure pas seulement des tickets : il décrit l'état du patrimoine Design System, son workflow, ses composants, ses audits et leur qualité.

## Message 2

Un indicateur doit toujours être accompagné de son périmètre et de sa fiabilité.

## Message 3

Une donnée manquante ne doit pas être transformée silencieusement en zéro ou en conformité.

## Message 4

Les snapshots permettent de suivre une trajectoire, pas seulement une photo instantanée.

## Message 5

Le projet commence simplement avec TypeScript + JSON + HTML, mais sépare déjà les contrats de données afin de permettre une évolution vers une API/backend/base de données.
