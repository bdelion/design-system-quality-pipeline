# Présentations

Le dossier contient des supports adaptés aux différents publics.

## Principe

La documentation métier est la source de vérité. Les présentations sont des vues adaptées à un public et ne doivent pas introduire de nouvelles règles.

## Publics

- Squad
- Managers
- Développeurs
- Lead Developers
- Designers
- Responsables qualité du développement
- Responsables accessibilité et handicap
- Clients / parties prenantes

## Format

Les supports sont écrits en Markdown avec Mermaid lorsque pertinent. Ils peuvent être transformés ultérieurement en HTML, PDF ou un outil de présentation sans changer le fond.

## Règle

Chaque support doit indiquer sa date/version documentaire et renvoyer vers les spécifications de référence.
