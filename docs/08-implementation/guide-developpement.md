# Guide de développement

## Stack observée

- Node.js >= 20.
- TypeScript.
- ESM.
- Commander.
- YAML.
- Vitest.
- ESLint.
- `tsx` pour exécution TypeScript.

## Commandes

```bash
npm install
npm run typecheck
npm test
npm run lint
npm run pipeline
```

## Principe

Une évolution métier doit idéalement être accompagnée de :

1. mise à jour de la spécification concernée ;
2. décision si le point était ouvert ;
3. modification du modèle/configuration ;
4. tests ;
5. documentation technique ;
6. mise à jour de la présentation si le changement est visible pour un public métier.
