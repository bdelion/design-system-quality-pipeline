# Fixtures

Le dépôt contient :

- `fixtures/github.json` : fixture de démonstration ;
- `fixtures/my-real-dataset-anonymized.json` : fixture anonymisée issue d'un jeu réel ;
- rapport de validation associé.

L'anonymisation doit préserver les sémantiques métier listées dans `docs/05-donnees/raw-dataset.md` tout en anonymisant les identifiants et données personnelles/techniques nécessaires.
