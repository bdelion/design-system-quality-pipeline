## Correction Grooming observée dans le même jeu

Le label source est **`📌 Grooming`**. La première correction de #125 ne reconnaissait que `Grooming`. Le matcher optionnel `issuePolicy.grooming`, avec la même structure `{ labels, prefixes }` que les autres conventions, prend désormais en charge par défaut ces deux valeurs exactes. Un matcher explicite remplace ce défaut, y compris une liste vide pour désactiver cette interprétation. Aucun retrait approximatif d’emoji ni correspondance par sous-chaîne n’est appliqué. Cette correction est indépendante de l’arbitrage sur les audits.
