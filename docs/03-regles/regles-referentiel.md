# Règles référentielles

Le catalogue est utilisé comme référence des composants.

La DQ actuelle DQ-006 signale un composant dont la source de découverte est `suggested`, c'est-à-dire absent du catalogue attendu.

La normalisation de version doit permettre de rapprocher `1.1.0` et `1.1.0-Audit` si le suffixe est configuré.

**À confirmer :** la politique exacte de présence obligatoire d'un composant dans le catalogue pour chaque type d'indicateur.
