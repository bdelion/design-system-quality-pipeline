# Règles workflow

Les règles workflow doivent être évaluées avec au minimum :

```text
Issue Type
+ Project Status
+ Labels
+ Iteration
+ Milestone
+ Velocity
+ PR / Branch
```

Le workflow source montre que les contraintes varient selon Standard, Epic, Audit, Release et Conception.

**Proposition d'implémentation future :** une matrice de règles par `workflowProfile` plutôt qu'un ensemble de règles globales. Cette proposition est issue des échanges et n'est pas encore implémentée.
