# DQ-025 — Version PROD cible indéterminable

## Décisions métier

D-200 à D-204 et D-231.

## Détection

L’Issue Audit est conservée mais aucun Audit complet n’est matérialisé lorsqu’une Version PROD cible ne peut pas être reliée.

## Politique

- Sévérité : `WARNING`
- Action : `include`
- La donnée source reste conservée dans le Snapshot.
