# DQ-005 - Pull request fusionnée et issue ouverte

**Sévérité :** `WARNING`  
**Action :** `include`

## Objectif

Repérer une incohérence entre l'état d'une pull request et celui de l'issue qu'elle est censée corriger.

## Déclenchement

La règle se déclenche lorsqu'une pull request est `merged` alors que l'issue liée est encore `OPEN`.

## Conséquence

Les données sont conservées et incluses, mais la qualité du lien issue/PR est signalée.

## Correction attendue

Vérifier l'issue GitHub et la relation de clôture. Fermer l'issue si la correction est effectivement livrée, ou corriger le lien si la pull request ne la concernait pas.
