# DQ-011 - Anomalie Done + Closed sans correctedAt fiable

## Règle

Une Anomalie dont le Project est canoniquement `DONE` et dont l’Issue GitHub est `CLOSED` doit disposer d’un `correctedAt` déterminable à partir d’une transition Project `DONE` unique.

Si l’historique est absent ou ambigu, la date reste absente conformément à D-188 et une réserve `WARNING` est produite. Aucune date de fermeture ou de collecte n’est utilisée comme fallback.

## Impact

L’Anomalie reste visible. Les métriques qui nécessitent une date de correction fiable deviennent partielles ou inconnues selon leur dépendance à `correctedAt`.
