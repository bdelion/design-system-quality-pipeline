# DQ-011 - Issue Type non déclaré

**Sévérité :** `WARNING`
**Action :** `include`

La règle se déclenche lorsqu'une Issue porte une valeur brute d'Issue Type
qui ne correspond à aucune valeur configurée dans
`github.issueTypes.keywords`. L'Issue et sa valeur brute restent
conservées ; le signalement affiche cette valeur et renvoie vers l'Issue
GitHub source afin de faciliter l'évolution de la configuration.

Cette réserve ne bloque pas le pipeline et n'affecte directement aucun
KPI.
