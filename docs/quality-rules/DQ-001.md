# DQ-001 - Criticité absente

**Sévérité :** `ERROR`  
**Action :** `exclude`

## Objectif

Empêcher qu'une anomalie sans criticité soit comptabilisée dans les KPI qui nécessitent une classification (`blocking`, `major` ou `minor`).

## Déclenchement

La règle se déclenche lorsque `anomaly.criticality` est absente après normalisation.

## Conséquence

L'anomalie reste présente dans le snapshot et dans les données normalisées, mais elle est exclue du KPI concerné. La fiabilité de l'indicateur devient partielle.

## Correction attendue

Ajouter une criticité reconnue au label ou à la donnée GitHub source, puis relancer la collecte et le pipeline.
