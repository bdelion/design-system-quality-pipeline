# DQ-029 — Référence normalisée orpheline

## Décisions métier

D-241.

## Détection

Contrôle défensif : toute référence matérialisée doit pointer vers une entité normalisée existante. Une relation non résolue doit normalement avoir été omise en amont.

## Politique

- Sévérité : `ERROR`
- Action : `exclude`
- La donnée source reste conservée dans le Snapshot.
