# DQ-015 - Catalogue historique absent au tag PROD

## Déclenchement

La Version PROD est identifiée par son tag Git exact `M.m.r`, mais `config/catalogue.yaml` est absent de l'arbre Git correspondant à ce tag.

## Interprétation

Le tag reste une preuve valide de l'existence de la Version. En revanche, la composition historique du Catalogue pour cette Version est indéterminable.

Conformément à D-211, le catalogue courant ne doit jamais être utilisé comme fallback et aucune relation `ComponentVersion` ne doit être inventée pour cette Version.

## Traitement

- Sévérité : `WARNING`
- Action : `include`
- Entité : `version`
- Impact KPI : aucun impact générique déclaré tant que les métriques historiques Component × Version ne sont pas introduites.
