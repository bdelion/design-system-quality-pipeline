# DQ-007 - Label inconnu

**Sévérité :** `WARNING`  
**Action :** `include`

## Objectif

Signaler un label explicitement marqué comme inconnu dans la source GitHub.

## Déclenchement

La règle se déclenche lorsqu'une issue contient le label configuré par `github.labels.unknown`.

## Conséquence

L'issue reste utilisable, mais une partie de sa classification est considérée comme incertaine.

## Correction attendue

Remplacer le label inconnu par un label métier reconnu, ou compléter la configuration si le nouveau label est légitime.
