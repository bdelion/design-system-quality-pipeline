# DQ-034 — Versions futures écartées

Une milestone reconnue ou un tag dépasse la version nominale déclarée dans le package du repository.

- Sévérité : INFO ; action : include pour l'activité des issues et PR.
- La normalisation écarte déjà ces versions, leurs présences historiques et leurs spécialisations accessibilité. Ce diagnostic explique le périmètre, sans invalider les données conservées.
- Entité : bibliothèque ; message avec borne et liste des versions exclues.
- Le RAW est conservé intégralement. Aucun audit n'est attribué par substitution.
- Tests : `tests/version-scope.test.ts`.

Voir [Périmètre des versions](../08-implementation/perimetre-versions.md).
