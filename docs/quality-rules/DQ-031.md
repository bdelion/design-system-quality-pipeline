# DQ-031 — Date Done absente

Done ET Closed sont prouvés, mais l'historique ne fournit aucune date Done valide.

- Sévérité : WARNING ; action : include.
- Le stock traité est conservé. Un délai peut utiliser Closed en tant qu'estimation explicite, séparée des dates Done.
- Impact : `issue.treatmentDelay.*` partiel, effectifs par provenance exposés.
- Aucun `Audit.completedAt` n'est inventé ; DQ-012 reste applicable aux audits.
- Tests : `tests/dashboard-consolidation.test.ts`.
