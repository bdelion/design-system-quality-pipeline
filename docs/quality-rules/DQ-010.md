# DQ-010 - Issue annulée rattachée à une milestone

**Sévérité :** `ERROR`  
**Action :** `exclude`

La règle se déclenche lorsqu'une issue annulée possède une milestone GitHub. Le rattachement est conservé dans les données RAW, mais l'issue est exclue de tous les KPI.

Les autres règles générales ne sont pas appliquées à une issue annulée.
