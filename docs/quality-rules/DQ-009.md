# DQ-009 - Nexus indisponible

**Sévérité :** `WARNING`  
**Action :** `include`

## Objectif

Rendre visible l'absence de preuve de release lorsque Nexus n'est pas disponible.

## Déclenchement

La règle se déclenche lorsque `raw.nexusAvailable` vaut `false`.

## Conséquence

Les données GitHub restent incluses, mais les indicateurs dépendant des preuves de release sont considérés comme inconnus ou partiels.

## Correction attendue

Rendre la source Nexus disponible et alimenter `nexusAvailable` avec le résultat réel de la collecte.
