# DQ-030 — État métier non prouvé

Une issue fermée sans Done effectif, un statut Project non reconnu ou des contextes contradictoires ne prouvent pas une terminaison.

- Sévérité : WARNING ; action : include.
- Les issues restent consultables ; elles ne deviennent pas traitées par le seul Closed.
- Impact : métriques génériques `issue.*` partielles. Les dates et les preuves Project restent visibles.
- Tests : `tests/dashboard-consolidation.test.ts` et scénarios navigateur.
