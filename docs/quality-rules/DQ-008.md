# DQ-008 - Issue annulée référencée par une pull request

**Sévérité :** `ERROR`  
**Action :** `exclude`

Une issue est considérée comme annulée dès qu'au moins un GitHub Project associé porte un statut configuré dans `github.cancelledProjectStatuses`, par défaut `Cancelled`.

La règle se déclenche si cette issue est reliée à une pull request par son texte, sa timeline ou la relation Development GraphQL. L'issue reste conservée pour la traçabilité, mais elle ne contribue à aucun KPI.

Les autres règles générales ne sont pas appliquées à une issue annulée.
