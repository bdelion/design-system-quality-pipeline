# DQ-003 - Parents multiples

**Sévérité :** `ERROR`  
**Action :** `exclude`

## Objectif

Garantir qu'une anomalie est rattachée à un seul audit parent identifiable.

## Déclenchement

La règle se déclenche lorsqu'une anomalie possède une criticité et plus d'un identifiant dans `parentRefs`.

## Conséquence

L'anomalie reste visible, mais elle est exclue des indicateurs qui dépendent de son rattachement à un audit.

## Correction attendue

Corriger les relations parent dans la source GitHub afin de ne conserver qu'un audit parent.
