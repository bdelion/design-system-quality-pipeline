# DQ-016 - Catalogue historique invalide au tag PROD

## Déclenchement

La Version PROD est identifiée par son tag Git exact `M.m.r` et `config/catalogue.yaml` existe à ce tag, mais son contenu ne peut pas être validé comme Catalogue exploitable.

## Interprétation

La Version est conservée. Sa composition historique reste indéterminable : une donnée invalide ne constitue ni une preuve de présence ni une preuve d'absence d'un Component.

Conformément à D-212, le catalogue courant ne doit jamais être utilisé comme fallback et aucune relation `ComponentVersion` ne doit être inventée pour cette Version.

## Traitement

- Sévérité : `WARNING`
- Action : `include`
- Entité : `version`
- Impact KPI : aucun impact générique déclaré tant que les métriques historiques Component × Version ne sont pas introduites.
