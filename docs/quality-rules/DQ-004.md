# DQ-004 - Pull request de correction absente

**Sévérité :** `WARNING`  
**Action :** `include`

## Objectif

Signaler une anomalie déclarée comme terminée sans preuve de pull request associée.

## Déclenchement

La règle se déclenche lorsqu'une anomalie est `done` et que `pullRequestRefs` est vide.

## Conséquence

L'anomalie reste incluse dans les données et les KPI, mais le résultat est marqué comme moins fiable.

## Correction attendue

Relier l'issue à la pull request correspondante via une référence de fermeture, un événement GitHub ou la relation Development récupérée par GraphQL.
