# DQ-006 - Composant absent du catalogue

**Sévérité :** `WARNING`  
**Action :** `include`

## Objectif

Identifier les composants détectés dans GitHub qui ne font pas partie du catalogue de référence.

## Déclenchement

La règle se déclenche lorsque `discoverySource` vaut `suggested`.

## Conséquence

Le composant est conservé et visible, mais ses métadonnées de référence peuvent manquer et les KPI sont accompagnés d'une réserve.

## Correction attendue

Ajouter le composant à [`config/catalogue.yaml`](../../config/catalogue.yaml) après validation de son nom et de ses métadonnées.
