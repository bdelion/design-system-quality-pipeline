# DQ-013 - Anomalie Project Done avec Issue ouverte

## Règle

Une Anomalie dont le statut Project courant est canoniquement `DONE` alors que son Issue GitHub est encore `OPEN` présente une incohérence de preuves au regard de D-140 et des règles de traitement.

La transition `DONE` reste un fait historique ; l’Issue n’est pas fermée artificiellement.

## Impact

L’Anomalie reste visible avec une réserve `WARNING`. Les métriques de correction conservent les faits disponibles mais leur fiabilité est dégradée.
