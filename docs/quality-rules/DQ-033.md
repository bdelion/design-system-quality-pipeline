# DQ-033 — Borne package indéterminée

La version du package racine sur la branche par défaut n'est pas collectée, est absente ou invalide. La limite des versions analysables ne peut pas être garantie.

- Sévérité : WARNING ; action : include, avec fiabilité partielle des métriques d'audit, anomalie, patrimoine et composant × version.
- Entité : bibliothèque ; provenance repository conservée dans le modèle normalisé.
- Les données restent incluses pour compatibilité ; aucun plafond n'est inventé à partir des milestones, tags ou configurations d'audit.
- Remédiation : recollecter le package puis régénérer la référence et le snapshot.
- Tests : `tests/version-scope.test.ts`.

Voir [Périmètre des versions](../08-implementation/perimetre-versions.md).
