# DQ-014 - Audit Project Done avec Issue ouverte

## Règle

Un Audit dont le statut Project courant est canoniquement `DONE` alors que son Issue GitHub est encore `OPEN` n’est pas réalisé au sens de D-141.

Aucun `completedAt` n’est produit et l’Issue n’est pas fermée artificiellement.

## Impact

L’Audit reste visible avec une réserve `WARNING`, mais il est exclu des métriques qui exigent un Audit réalisé.
