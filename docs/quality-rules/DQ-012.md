# DQ-012 - Audit Done + Closed sans completedAt fiable

## Règle

Un Audit dont le Project est canoniquement `DONE` et dont l’Issue GitHub est `CLOSED` doit disposer d’un `completedAt` déterminable à partir d’une transition Project `DONE` unique.

Si l’historique est absent ou ambigu, `completedAt` reste absent conformément à D-188 et une réserve `WARNING` est produite.

## Impact

L’Audit reste visible et son état source est conservé, mais les lectures dépendant d’une date de réalisation fiable sont signalées comme partielles.
