# Exécuter le parcours local

Le parcours courant est : liste de repositories → collecte avec profil DSQ livré → dataset autonome anonymisé → contrôle → pipeline hors réseau → dashboard dans une sortie explicite.

Les commandes et options sont décrites dans [le guide d’utilisation](08-implementation/guide-utilisation.md). Le format transportable et la migration sont décrits dans [Datasets autonomes](08-implementation/datasets.md).
