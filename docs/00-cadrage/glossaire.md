# Glossaire

| Terme          | Définition retenue dans le projet                                        | Statut                                     |
| -------------- | ------------------------------------------------------------------------ | ------------------------------------------ |
| Repository     | Dépôt GitHub analysé                                                     | Implémenté                                 |
| Library        | Bibliothèque analysée, actuellement associée à un repository             | Implémenté / évolution monorepo prévue     |
| Component      | Composant du Design System                                               | Métier                                     |
| Issue          | Élément de travail GitHub                                                | Source                                     |
| Issue Type     | Nature déclarée de l'issue : BUG, AUDIT, EPIC, etc.                      | Source / configuration                     |
| Label          | Caractéristique ou classification GitHub                                 | Source                                     |
| Project status | Position de l'issue dans le workflow GitHub Project                      | Source                                     |
| Iteration      | Sprint / période de travail                                              | Métier, modèle à compléter                 |
| Milestone      | Objet GitHub utilisé dans les sources pour version, audit ou autres lots | Source, sémantique à normaliser            |
| Audit          | Évaluation d'un composant selon un objectif d'audit                      | Modèle normalisé                           |
| Anomaly        | Problème qualité analysé par le pipeline                                 | Modèle normalisé                           |
| Criticality    | Niveau de criticité                                                      | Domaine à préciser selon type              |
| Category       | Famille de classification d'une anomalie                                 | Modèle normalisé                           |
| Velocity       | Estimation de charge déclarée sur une issue                              | Besoin métier, non présent dans RAW actuel |
| Snapshot       | État calculé du système à un instant donné                               | Implémenté                                 |
| Flow           | Évolution observable entre deux snapshots                                | Implémenté                                 |
| DQ             | Data Quality                                                             | Implémenté                                 |
| KPI / Metric   | Indicateur calculé                                                       | Implémenté                                 |
