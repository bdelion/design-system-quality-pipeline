# Sources externes

## Sources actuelles

- GitHub.
- Catalogue YAML.
- Fixture locale.
- `nexusAvailable` est représenté dans le RAW.

## Sources nécessaires pour des indicateurs futurs

Les demandes client concernant les applications consommatrices du Design System, les applications qui devraient l'utiliser et la fréquence d'utilisation d'un composant ne peuvent pas être déduites de manière fiable du modèle GitHub actuel.

Il faudra une ou plusieurs sources complémentaires.

**Important :** aucune technologie, API ou base de données externe précise n'est imposée par les sources disponibles.
