# ADR-003 — Contrat Metrics V2

**Statut : DÉJÀ IMPLÉMENTÉ**

## Décision observée

`Analytics.metrics` constitue le contrat analytique de référence. Les propriétés KPI historiques sont des projections de compatibilité.

## Conséquence

Il ne faut pas recréer des définitions concurrentes dans le dashboard ou dans des propriétés legacy.
