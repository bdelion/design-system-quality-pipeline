# ADR-004 — Documentation comme produit versionné

**Statut : PROPOSÉ / À VALIDER PAR LA SQUAD**

## Proposition

Structurer la documentation en cadrage, métier, workflow, règles, indicateurs, données, architecture, décisions et implémentation.

## Motivation

Les sources actuelles mélangent règles, hypothèses, questions et code. La structure proposée permet de faire évoluer chaque niveau sans confondre spécification et implémentation.
