# Architecture Decision Records

Les ADR documentent les décisions qui engagent la structure du projet.

## Règles

- Une décision doit être datée.
- Elle indique son statut.
- Elle explique le contexte et les alternatives connues.
- Une hypothèse non validée n'est pas un ADR.
- Une décision métier doit être distinguée d'une décision technique.

## ADR initiales

- ADR-001 : snapshots comme format de persistance de la phase actuelle.
- ADR-002 : séparation RAW / modèle normalisé.
- ADR-003 : métriques V2 comme contrat analytique.
- ADR-004 : documentation structurée et versionnée.
