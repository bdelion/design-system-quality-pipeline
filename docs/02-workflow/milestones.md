# Milestones

Les milestones sont utilisées comme :

- versions ;
- versions d'audit ;
- regroupements de planification ;
- autres lots décrits dans le workflow.

Le titre et l'état de milestone sont conservés dans le RAW.

Une normalisation de version doit pouvoir traiter un suffixe configurable comme `-Audit`.

**À clarifier :** comment distinguer automatiquement les différents usages d'une milestone lorsque son titre n'est pas suffisamment explicite.
