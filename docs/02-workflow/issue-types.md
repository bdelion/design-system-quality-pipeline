# Issue Types

Issue Types explicitement présents ou utilisés dans les sources :

- BUG
- FEATURE
- TASK
- EPIC
- AUDIT
- NEW_COMPONENT
- OTHER / UNKNOWN selon les données.
- RELEASE.
- CONCEPTION.

## Point de vigilance

Le code RAW actuel encode explicitement : `EPIC`, `AUDIT`, `BUG`, `NEW_COMPONENT`, `FEATURE`, `OTHER`, `UNKNOWN`.

Les sources de workflow utilisent également Release et Conception. Leur représentation technique n'est pas équivalente à une couverture complète de ces workflows.

**À confirmer :** taxonomie canonique et correspondance exacte des valeurs GitHub réelles.
