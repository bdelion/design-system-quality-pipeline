# Iterations / Sprints

Le workflow source indique :

- iterations de trois semaines ;
- du lundi au vendredi ;
- numérotation incrémentale ;
- une issue non close peut être reportée vers une autre iteration ou retirée d'une iteration ;
- dans certains cas, le retrait devrait conduire à Backlog + Grooming ou à un statut dédié.

Les indicateurs demandent également les jours ouvrés en tenant compte des jours fériés en France.

**Limitation actuelle :** le modèle RAW observé dans le ZIP ne possède pas encore de structure dédiée aux iterations. Les indicateurs de sprint détaillés ne doivent donc pas être considérés comme implémentés par défaut.
